# axiom-cegis v0.2.0

Рабочий CEGIS-цикл. Синтезатор начинает с набора примеров, предлагает самую дешёвую программу, согласованную с ними, а
затем запрашивает у `axiom-symbolic` либо универсальное доказательство, либо контрпример. Контрпримеры добавляются в
набор примеров, пока цикл не сойдётся.

Для встроенного эксперимента `abs` ожидаемая траектория такая:

```text
x        -> контрпример x < 0
-x       -> контрпример x > 0
branch   -> VALID для всех целых
```
